# التحقق — الريلز 2.4.0 / 16

13 سبتمبر 2026. يحافظ الإصدار على دورة العميل والإدارة والموصّل السابقة ويضيف الريلز.

## المنفذ

- نافذة فيديو عمودية بالسحب، وتشغيل الفيديو الظاهر فقط، والإيقاف عند الخروج أو إخفاء التطبيق.
- توفير البيانات مفعّل افتراضياً؛ لا يُحمّل الفيديو قبل النقر. تشغيل تلقائي مكتوم اختياري.
- اختصار أحمر يسار الرئيسية يتمدد لليمين، مع أغلفة أحدث الفيديوهات وعنوان وعدد قابلين للتحكم.
- حلقات حول مجموعات التسوق، وزر فيديو في بطاقة الصنف وتفاصيله، وتمييز المقاطع المشاهدة محلياً.
- الإدارة ← الرئيسية أو تسوق ← الريلز ومصادر الفيديو، مع نافذة مستقلة للإعدادات والحلقات.
- اختيار الأصناف بالبحث والباركود، وربط المجموعات، وتعديل العناوين والأغلفة والجدولة وترتيب المصادر.
- اكتشاف روابط Item.description ومرفقات File المرتبطة بالصنف؛ دفعات إضافية في الجلب اليدوي.
- جلب تلقائي اختياري للمقاطع العامة: أحدث 20 صنفاً، والصنف أو المجموعة التي تُتصفّح، مع تخزين مؤقت لخمس دقائق.
- روابط MP4/WebM مباشرة، ورفع إلى استضافة الخدمة حتى 5 ميجابايت. صفحات مواقع التواصل تفتح في مصدرها.
- استيراد المرفق الخاص يحتاج صلاحيات المدير وموافقة صريحة على نشر نسخة، ولا يكشف رابط ERP الخاص للعميل.
- الحفظ كمسودة ثم النشر. خدمة الملفات المستضافة تتحقق من النشر والمدة وجيل التكامل وتدعم HTTP Range.
- دليل مصوّر داخل الإدارة، يحتوي الآن على 51 موضوعاً.

## حدود التحقق والتشغيل

- لم يثبت الاتصال الحي بخادم ERPNext الخاص بالمستخدم؛ الفحص السابق أعاد HTTP 403 / 1010. اختبارات اكتشاف الفيديو والصلاحيات استخدمت ERP محاكياً.
- لم تُعدّل أصناف أو مستندات النظام الحقيقي، ولم تُرسل إشعارات إلى العملاء أثناء الاختبار.
- معاينة ChatGPT خاصة بصاحبها؛ تشغيل APK بالبيانات الحية يحتاج نشر الخدمة المستقلة على عنوان HTTPS متاح ثم إعداد عنوانها وفق دليل الربط. ليست ملفات APK متصلة بخادم عام الآن.
- لم يُشغّل التطبيق على جهاز Android أو محاكي. بُنيت ملفات التثبيت وتم التحقق منها، ويبقى اختبار الكاميرا وترميز الفيديو على الهاتف مطلوباً.
- روابط صفحات YouTube وFacebook وInstagram وVimeo تفتح خارج مشغل الفيديو. التشغيل داخل الريلز يحتاج رابط MP4/WebM النهائي؛ لا تتبع نسخة Android تحويلات مضيف الفيديو الخارجي.
- لا تحويل ترميزات أو ضغط فيديو آلي، ولا تحميل فيديو أكبر من 5 ميجابايت في هذا الإصدار. علامة المشاهدة محلية وليست إحصاءً تسويقياً على الخادم.
- البيانات التلقائية العامة تظل خاضعة لصلاحيات حساب التكامل؛ حساب المدير الشخصي منفصل عن حساب تكامل العملاء.

## مسار المراجعة

1. افتح الإدارة ثم الريلز ومصادر الفيديو.
2. ارفع MP4/WebM صغيراً أو أضف رابطاً عاماً مباشراً، واختر الصنف والمجموعة ثم احفظ.
3. اضبط الاختصار والحلقات وأولوية المصادر وتوفير البيانات.
4. انشر المتجر من نافذة النشر والجدولة.
5. افتح العميل: الاختصار الأحمر ثم الفيديو، أو حلقة المجموعة أو زر فيديو الصنف.
6. بعد اتصال ERPNext فعلياً، اختبر الجلب بصنف معلوم وفيديو عام واحد قبل تفعيل الجلب التلقائي.
