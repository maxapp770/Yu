حساب التكامل لا يملك System Manager. لم يُختبر الدخول أو تشغيل التقارير على ERP بحساب المدير الحقيقي لأنه محفوظ لدى المستخدم. لم ينشأ طلب أو مستند بيع على النظام الحقيقي خلال هذه الاختبارات.

## طريقة التجربة الحالية

1. ادخل رابط المساحة بحساب ChatGPT المالك.
2. افتح التطبيق الإداري وسجل الدخول بحسابك الإداري في ERPNext. لا تستخدم admin/123456 للوصول للخدمة؛ هذا للمراجعة المحلية في APK فقط.
3. اختر إعدادات الشركة والأسعار والمخزن، ثم فعّل الكتالوج والوظائف المرغوبة. راجع الأذونات والأسعار قبل فتح الطلبات.
4. عدل القسم المطلوب واحفظ المسودة، ثم انشرها. افتح واجهة العميل وتحقق من ظهور التعديل.
5. أنشئ حساب عميل مرتبطاً بسجل Customer قبل اختبار الطلبات. أي طلب بعد تفعيلها يكتب مسودة حقيقية في ERP؛ اختر بيانات التجربة المناسبة.

## الحدود والأجزاء المتبقية

- [ ] عنوان HTTPS ثابت للخدمة يتاح لتطبيقات Android. مساحة ChatGPT خاصة تتطلب دخول المنصة، ولا تصلح نقطة API مباشرة للـAPK المرفق. عنوان العميل في البناء الحالي https://hec-service.invalid، والنسخ للمراجعة المحلية.
- [ ] اختبار الكاميرا والباركود والمشاركة وحفظ التقرير على هاتف Android؛ لا هاتف أو محاكي متاح في البيئة الحالية.
- [ ] مطابقة الفلاتر الخاصة بالتقارير وتخصيصات ERP الفعلية. التقارير ذات JavaScript خاص تحتاج تعريف فلاتر معتمداً؛ لا ننفذ كود التقرير الخارجي داخل التطبيق. Report Builder غير مدعوم حالياً.
- [ ] دورة التوصيل الفعلية والتحصيل والمرتجعات والولاء المالي والعمولات والمحفظة وأتمتة التسويق من الحركة التاريخية. الواجهات/المعاينات السابقة لا تعني اتصال هذه الدورات بالـERP؛ ميزاتها غير المدعومة مغلقة على الخدمة.
- [ ] إعداد Push ومزود الإرسال؛ الإشعارات الحالية داخل التطبيق وتُحدّث عند الاستخدام، وليست دفعاً إلى جهاز مغلق.
- [ ] اعتماد الطلبات أو الفواتير والمدفوعات آلياً؛ الحالي مسودات Sales Order فقط.
- [ ] جدولة دائمة في مساحة Sites؛ النشر المجدول يُفعّل عند أول طلب بعد موعده. تنفيذ Python يتضمن عاملاً مستقلاً للجدولة.
- [ ] محول نقل بيانات مساحة Sites إلى قاعدة خدمة Python. الصيغ ومفاتيح التشفير مختلفة؛ يلزم نقل صريح واختبار قبل التحويل.
- [ ] اعتماد نشر إنتاجي وحزمة Google Play ومراقبة ونسخ احتياطية واستعادة تحت الحمل.

المساحة المؤقتة محدودة بـ200 حساب عميل و300 طلب محفوظ و25 نسخة منشورة، مع سقف 1.5MB لحالة المتجر الأساسية. يحد التقرير المحمل بـ2000 صف. لا تعتمد عليها لمتجر كامل قبل مراجعة السعة وخطة النقل. فلاتر واجهة التسويق تعمل على الكتالوج المحمل؛ لا يعني ذلك جلب كل أصناف ERP مرة واحدة.

## إعداد ERPNext وتغيير التكامل

لا يلزم تثبيت hec_bridge أو إضافة DocType في المسار الحالي. راجع SETUP-GUIDE-2.2.md وservice/README.md. مجلد integration/frappe ووثائق الإصدارات الأقدم مرجع تاريخي فقط.

تغيير ERP URL أو المفاتيح: اختبار من الإدارة، صيانة وتسوية المعلق، تفعيل ثم إعادة الدخول ومراجعة الروابط والأسعار. النطاق الجديد قد يتطلب تعديل قائمة السماح بالخادم. تغيير خادم الخدمة تحت نفس النطاق وبياناته لا يحتاج APK جديداً؛ تغيير نطاق الخدمة المضمّن في التطبيقات الحالية يحتاج تحديثاً لها. لا تعد هذه النسخة بنقل تلقائي بين مسارات التخزين المختلفة.
