# الهيثم HEC+ — تحديث 1.4 للمرحلة الأولى

تطبيق Android بواجهات عربية محلية، مبني على الصور والفيديو المتاحين. هذا التحديث يجمع أدوات الإدارة السابقة ويضيف دخول المراجعة الذي طلبه صاحب التطبيق. ربط ERPNext مؤجل.

## الدخول ومراجعة اللوحة

1. ثبّت `HEC-phase1-debug.apk` كتحديث على Android 10 أو أحدث.
2. افتح **حسابي ← لوحة تحكم المتجر**.
3. اسم المستخدم **admin**، وكلمة المرور **123456**.
4. اختر القسم، ثم التبويب، واضغط «تحميل السجلات» ثم «عرض وتعديل».
5. احفظ، وارجع إلى المتجر لمشاهدة التعديل. التغييرات محلية على هذا الجهاز وتبقى بعد إعادة التشغيل.

الحساب مخصص للمراجعة، ولا يمثل دور System Manager أو جلسة ERPNext. لا تستخدم هذه النسخة لإدارة بيانات متجر حقيقي. يظل نموذج صلاحيات الخادم منفصلاً، ويُستبدل ناقل المراجعة في إصدار الربط.

## ما أضيف

- 6 أقسام إدارة و39 تبويباً؛ أُدرجت الأدوات القديمة الـ22 ضمن التنظيم الجديد دون تكرارها.
- إدارة الرئيسية: النصوص، ترتيب الأجزاء وإخفاؤها، الصور والبانرات ومدة عرضها ووجهتها، الاختصارات والصفقات والمجموعات والأصناف والتذييل.
- إدارة تسوق: أسماء المجموعات والتصنيفات الفرعية وصورها ووجهاتها، بانر كل مجموعة، اختيار الأصناف، جديد تلقائي أو يدوي مع الاستبعاد وحد العرض، شبكة أو قائمة.
- العروض: إجمالي الحزمة وتوزيعه بمبلغ الوحدة أو نسبة من الإجمالي أو توزيع الباقي تلقائياً؛ تحقق من الفروق والكسور، وإضافة العرض كاملاً للسلة.
- مشاركة السلة عبر نافذة المشاركة الأصلية في Android؛ رسالة بالتفاصيل ورابط يتيح المراجعة ثم الدمج في سلة مستخدم آخر.
- زر حذف واضح لكل صنف بالمفضلة وحذف الكل مع تأكيد.
- شريط تنقل شفاف، مع دائرة اختيار سوداء وعنابية وذهبية ولمعة تحترم تقليل الحركة، ومساحة تمرير كافية لآخر المحتوى.

## مشاركة السلة

من السلة اضغط رمز المشاركة، ثم اختر التطبيق. يحتوي الرابط على الأصناف والخيارات والكميات والأسعار وقت المشاركة، دون اسم العميل أو هاتفه أو عنوانه. يستطيع حامل الرابط عرضها. يفتح زر الصفحة تطبيق الهيثم؛ داخل التطبيق يراجع المستلم الأصناف ثم يختار دمجها، دون استبدال سلته الحالية. يعاد التسعير وفق كتالوج جهاز المستلم حالياً، ولا تعتمد أسعار الرسالة كسلطة سعرية.

صفحة الاستقبال: https://hec-shared-cart.fadhel-motaher.chatgpt.site

تتوافر أيضاً خانة لصق الرسالة أو الرابط في السلة. الأصناف غير المتاحة تظهر بوضوح ولا تُضاف. التعديلات المحلية الخاصة بمنتجات أو حزم جديدة لا تنتقل إلى أجهزة الآخرين؛ يلزم الكتالوج المشترك عند الربط. الحزمة تشارك كصنف أب، وتعرض مكوناتها حسب تعريفها في كتالوج المستلم.

## الحدود الحالية

الطلبات والمحفظة والتحصيل والمرتجعات والرسائل سجلات أو مسودات محلية؛ لا تنفيذ مالي أو مراسلات خارجية. رفع صور وفيديوهات جديدة يتطلب مخزن وسائط لاحقاً؛ محرر الصور يختار من الوسائط المرفقة حالياً. لا يوجد تسجيل دخول فعلي للعملاء أو اتصال ERPNext. لا تُدّعى مطابقة بكسلية كاملة أو شهادة أمان إنتاجية.

لا توجد صلاحيات شبكة أو كاميرا في APK الحالي. البحث بكود الصنف يعمل محلياً، أما مسح الكاميرا الفعلي فمؤجل. روابط الخدمات التي لم يقدم لها عنوان رسمي تبقى غير مفعلة. ملفات التاريخ توثق مراحل سابقة ولا تصف صلاحيات هذا الإصدار.

## الإصدار والبناء

`1.4.0-phase1`، رمز الإصدار `5`، المعرف `com.alhaitham.hec.preview`؛ توقيع الاختبار نفسه لتحديث 1.3 مع الاحتفاظ بالبيانات. يتطلب البناء Java 17 وAndroid SDK Platform 35 وBuild Tools 35.0.0:

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export HEC_DEBUG_KEYSTORE=/private/path/hec-preview-debug.keystore
./build-apk.sh
```

الناتج `build/HEC-phase1-debug.apk`. المفتاح غير مضمن بالمصدر. مشروع Gradle/Android Studio موجود؛ لم تُختبر مزامنة Android Studio هنا.

## الفحوص

```bash
node tests/experience.cjs
node tests/commerce.cjs
node tests/management.cjs
node tests/security.cjs
python3 tests/management_guard_test.py
HEC_CHROME_BIN=/path/to/chrome node tests/review-browser.cjs
HEC_CHROME_BIN=/path/to/chrome node tests/browser.cjs
```

تتطلب فحوص المتصفح Playwright. `management-browser.cjs` يحيل إلى فحص المراجعة الجديد. راجع `docs/TEST_RESULTS_AR.md` لنتائج التنفيذ وحدوده، و`docs/MANAGEMENT_AR.md` لتنظيم اللوحة، و`docs/ERP_NEXT_PHASE_AR.md` لعقد التكامل.
