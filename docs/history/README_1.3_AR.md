# تطبيق الهيثم HEC+ — المرحلة الأولى 1.3

تطبيق أندرويد بواجهات محلية مضمّنة داخل WebView، مبني على الصور ومراجعة فيديو الشاشة الرئيسية. يعمل دون خادم؛ ربط ERPNext وREST API مؤجل للمرحلة التالية.

## الجديد

- الرئيسية بتسلسل الفيديو: اختصارات 4×2، ست حملات، رواق صفقات، الساعة الذهبية، ثمانية أقسام، مقترحات، منتجات جديدة وأفضل المبيعات وروابط التواصل.
- عدادات تنتهي فعلياً ولا تتجدد عند كل تشغيل، وصفحات حملات وبحث مقيّد بمنتجات الحملة.
- لوحة تصفية جانبية للأسعار والفئات والعلامات، ومسح وتطبيق، وشريط بحث عنابي.
- حساب العميل بقائمة الاثني عشر بنداً والإحصاءات الثلاثة، وملف شخصي، إيميل، معاينة تغيير كلمة المرور، محفظة، مرتجعات، نقاط، تسويق بالعمولة، رسائل، إشعارات ولغة.
- حفظ آمن من الأخطاء لمسودات الواجهات الجديدة، مع تحقق من المدخلات وتراجع عند فشل التخزين. لا تُخزّن كلمات مرور، ولا تُنفذ مدفوعات أو طلبات حقيقية.
- الترحيل إلى مخطط بيانات 3 يحافظ على بيانات HEC+ 1.2. إصدار التطبيق 1.3.0-phase1، رمز 4، المعرف نفسه `com.alhaitham.hec.preview` والتوقيع التجريبي نفسه.

## التشغيل

ثبّت `HEC-phase1-debug.apk` كتحديث للهيثم HEC+ على Android 10 أو أحدث. احتفظ ببيانات التطبيق عند التثبيت. التطبيق الأول ذي المعرف `com.alhaitham.hec` مستقل؛ لا تُنقل بياناته تلقائياً.

ابدأ من الرئيسية وافتح عرض الساعة الذهبية أو أحد الأقسام. جرّب إضافة منتج، تغيير الكمية والخيارات، المفضلة، السلة، ثم حفظ مسودة الطلب. من حسابي افتح «معاينة الحساب» لتجربة الصفحات الشخصية محلياً. حفظ مسودة مرتجع يتطلب مسودة طلب سابقة، ويمنع تكرار كمية المنتج والخيار نفسه. الرسائل والمحفظة والتسويق بالعمولة تحفظ مسودات فقط.

تسجيل الخروج ينهي معاينة الصفحات الشخصية دون حذف المسودات. صفحة الخصوصية تتيح مسح بيانات العميل والمندوب كلٍّ على حدة. واجهات المندوب والتتبع السابقة محفوظة ويمكن الوصول إليها من حسابي وسجل الطلبات.

## حدود المرجع والمرحلة

هذه نسخة واجهات قابلة للاختبار، وليست متجراً إنتاجياً أو مطابقة بكسلية مؤكدة. صفحات المحفظة والمرتجعات والولاء والتسويق والرسائل الداخلية لم تظهر مكتملة في التسجيل؛ استُكملت بالهوية نفسها وببيانات محلية واضحة. بعض أصناف المرجع لا تتوافر لها صور أو أسعار كاملة، فتظل تصنيفات مع حالة فارغة عند غياب المنتجات. أضيفت الصور والمنتجات السبعة الجديدة التي أمكن تحديدها، فأصبح الكتالوج 19 منتجاً.

واجهة العميل تدعم العربية والإنجليزية وRTL/LTR. صور الإعلانات وأسماء المنتجات الأصلية تبقى بلغة المصدر؛ بعض نصوص واجهات المندوب والإدارة القديمة عربية. رابط Facebook مستخرج من QR بنر SHOP NOW في الفيديو ومفعّل. وجهات YouTube وInstagram وWhatsApp وGoogle Play ما زالت تحتاج الروابط الرسمية المؤكدة، وهي فارغة في `experience-data.js`. لا تُضف روابط تخمينية. آلية الفتح جاهزة وتقبل HTTPS على خدمات محددة وتفتحها خارج WebView من نقرة صريحة.

## المصدر

- `app/src/main/java/com/alhaitham/hec/MainActivity.java`: حاوية أندرويد وحدود الموارد والروابط وحوار الإغلاق.
- `app/src/main/assets/web/experience-data.js`: الحملات والأقسام والمنتجات المضافة وإعداد الروابط الرسمية.
- `app/src/main/assets/web/experience.js` و`experience.css`: الشاشات والتصفية وحساب العميل واللغة والحالات الجديدة.
- `app/src/main/assets/web/app.js`: السلة والتفاصيل والطلب والعناوين والتنقل؛ و`courier.js` لدور المندوب.
- `app/src/main/assets/web/storage.js`: التحقق والحدود والترحيل والتخزين المحلي.
- `docs/CHECKLIST_AR.md`: البنود الـ45 وحالة كل بند والقيود المتبقية.
- `docs/asset-provenance.json`: مصادر قصاصات الفيديو وإزالة حواف عناصر التحكم من الصور القديمة.
- `docs/TEST_RESULTS_AR.md`: نتائج التحقق وحدوده.

## البناء

يلزم JDK 17 وAndroid SDK Platform 35 وBuild Tools 35.0.0. استعد مفتاح اختبار HEC+ السابق من النسخة المحفوظة خارج المصدر، وحدد `HEC_DEBUG_KEYSTORE` أو ضعه في `~/.android/hec-preview-debug.keystore`. لا تغير المفتاح بين تحديثات هذا التطبيق التجريبي. لا يوجد مفتاح داخل المصدر.

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export HEC_DEBUG_KEYSTORE=/private/path/hec-preview-debug.keystore
./build-apk.sh
```

الناتج `build/HEC-phase1-debug.apk`. يتوفر أيضاً مشروع Android Studio وGradle Wrapper:

```bash
./gradlew assembleDebug
```

استخدم مسار SDK المباشر لإعادة البناء المطابق لطريقة هذه الجلسة. لم تُختبر مزامنة Android Studio في هذه الجلسة. مفتاح الاختبار ليس مفتاح إنتاج؛ يلزم توقيع وسياسات ونشر موثقة قبل إصدار المتجر.

## الاختبارات

```bash
node tests/experience.cjs  # يشغّل أيضاً 60 اختباراً سابقاً
node tests/security.cjs
```

لا تتطلب اختبارات البيانات اعتماديات إضافية. للفحص البصري والرحلات في المتصفح يلزم Playwright ومتصفح مثبت:

```bash
HEC_CHROME_BIN=/path/to/chrome node tests/browser.cjs
```

الفحص داخل متصفح لا يغني عن تجربة Android أو هاتف فعلي. يعمل WebView هنا بالرسم البرمجي الموروث من 1.2 لتوافق المحاكي القديم؛ يلزم قياس الأداء على الهواتف المستهدفة قبل النشر.


## لوحة التحكم المطلوبة

أضيفت 22 واجهة إدارة مع البحث والنماذج وحالات التحميل والفشل. لا تتاح إلا لدور System Manager من ERPNext بعد الربط؛ لا يوجد حساب أو زر مسؤول تجريبي في APK. تشمل الحماية انتهاء جلسة الإدارة وسحب الدور وإغلاق النماذج وحذف سياق الإدارة من الذاكرة. راجع `docs/MANAGEMENT_AR.md`، والعقد المعطل `management-api.js` وقالب حارس الخادم `integration/erpnext/management_guard.py`. صور اللوحة في docs/screenshots/management ناتجة عن اختبارات منفصلة لاستجابة خادم، وليست اتصالاً فعلياً.

اختبارات الإضافة: `node tests/management.cjs`، و`python3 tests/management_guard_test.py`، و`node tests/management-browser.cjs` مع Playwright ومتغير HEC_CHROME_BIN.
