# أمان إصدار 2.1

تطبيق العميل وتطبيق الإدارة منفصلان. ملفات الإدارة وحساب المراجعة والدليل مستبعدة فعلياً من APK العميل. الدخول المتصل للإدارة يفحص دور System Manager على الخادم عند كل إجراء؛ فصل الأيقونات لا يحل محل التفويض.

- اتصال Android يستخدم HTTPS والتحقق الافتراضي من الشهادة، ولا يتبع التحويلات. عمليات الجسر محددة بقائمة سماح، وأصول وصفحات WebView محلية ومعروفة. يوجد تصريح INTERNET للاتصال الأصلي وCAMERA للقارئ.
- كلمات المرور ومفاتيح API لا تحفظ على القرص أو في APK. تبقى جلسة الاتصال في الذاكرة. لا توجد في هذا الإصدار ميزة تذكر كلمة المرور أو مخزن Android Keystore للأسرار.
- حساب admin / 123456 متاح في معاينة الإدارة المحلية فقط ولا يمنح صلاحيات ERPNext. لا يوجد في بناء العميل.
- العميل يدخل بحسابه الشخصي. فحص الربط إلى Customer والشركة وملكية الطلبات والإشعارات يتم على الخادم، وليس بقيمة يرسلها الهاتف.
- حساب التكامل ينفذ العمل بصلاحياته الفعلية. يمنع تفعيل خدمات مالية أو تشغيلية لا يوجد لها محول منفذ. لا يفعّل المثبت Server Scripts ولا يمنح صلاحيات ERP عالمية.
- الخادم يعيد تسعير الطلب وتوليد مكونات الحزمة، ويستخدم معرف طلب لمنع التكرار. وضع الصيانة يمنع استقبال طلبات جديدة أثناء النقل.
- نشر المحتوى يتطلب حساب مدير، ويتحقق من نسخة المسودة. الاستعادة تنشئ إصداراً جديداً وتبقي التاريخ السابق. هوية المتجر تكشف استبدال قاعدة بيانات غير مطابقة.
- الكاميرا لا تحفظ صوراً. المشاركة لا تتضمن بيانات اعتماد. السلة والتفضيلات المحلية ليست مخزناً مناسباً للأسرار.

نجحت قراءة REST الفعلية بالمفاتيح المقدمة. لم تُثبت إضافة hec_bridge على الموقع؛ لذلك لم تنفذ اختبارات العزل أو الطلبات على قاعدة البيانات الحقيقية بعد. اختبارات الصلاحيات الحالية محلية، ولا تعادل اختبار اختراق أو فحص جهاز Android فعلي. النسخ موقعة بمفتاح مراجعة، وليست إصدار Google Play إنتاجياً معتمداً.

راجع RELEASE_2.1_AR.md والدليل المصور لمعرفة ما نُفذ وما يتطلب التركيب والاختبار.
