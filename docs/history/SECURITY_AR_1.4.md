# حدود أمان نسخة HEC 1.4

هذه نسخة محلية للمراجعة، دون ادعاء تدقيق مستقل أو ملاءمة لبيانات مالية حقيقية. أضيف **admin / 123456** بطلب المستخدم. الحساب ثابت داخل نسخة المراجعة ولا يصلح كوسيلة حماية إنتاجية؛ لا يُمنح به دور ERPNext ولا يتصل بخادم.

| المجال | ما نُفذ | الحد |
|---|---|---|
| WebView | أصل HTTPS محلي، قائمة موارد صريحة، منع الشبكة والملفات وcontent وmixed content، دون JavaScript bridge أو debugging | يستخدم JavaScript المرفق فقط |
| الحزمة | لا تصاريح شبكة/كاميرا، تعطيل النسخ الاحتياطي، منع HTTP الصريح | الطلبات الحقيقية غير مفعلة |
| الإدارة | جلسة ذاكرة، تحقق عند العمليات، خروج وحجب الروابط، منع ازدواج الحفظ وتعارض النسخ | admin/123456 مراجعة محلية مقصودة |
| النصوص | ترميز النصوص المتغيرة، صور محلية ووجهات مسموحة، CSP | رفع الوسائط يحتاج خدمة مستقلة |
| المشاركة | Android ACTION_SEND من نقرة صريحة، نص وروابط محددة الأصل، تحقق مستقل من الرسالة في Java وJS | أي حامل للرابط يستطيع قراءة الأصناف |
| رابط السلة | حدود للحجم والعدد والكميات والأكواد والخيارات، منع تكرار الصف نفسه، لا بيانات هوية أو أدوار | الأسعار المرسلة ليست أسعاراً معتمدة |
| الاستيراد | معاينة وتأكيد، إعادة تسعير من الكتالوج، دمج ذري، منع الإضافة المكررة بالنقرة نفسها | الكتالوج محلي حتى ERPNext |
| التخزين | فحص قيم وحدود وتراجع عند فشل حفظ السلة، لا تخزين لكلمات المرور المدخلة | localStorage غير مشفر إضافياً؛ ليس مخزن أسرار |
| التوقيع | نفس شهادة الاختبار للحفاظ على تحديث التطبيق | ليس توقيع نشر إنتاجي |

قبل تشغيل متجر حقيقي: إزالة حساب المراجعة من بناء الإنتاج، مصادقة خادمية وصلاحية System Manager لكل عملية إدارة، صلاحيات المستندات، إعادة حساب الطلب والعروض والمخزون على الخادم، جلسات قابلة للإبطال وأسرار محمية عبر Android Keystore، توقيع إنتاجي واختبارات هاتف وخصوصية واختبار اختراق.

البيانات في رابط السلة موجودة في fragment وليست طلب رفع سلة إلى خادم الصفحة. لا يتضمن الرابط اسم العميل أو عنوانه أو هاتفه. تبقى الرسالة قابلة للنسخ وإعادة الإرسال؛ هذا يوافق طلب مشاركتها مع أي حامل لها. أزرار الاستيراد لا تنفذ طلباً أو دفعاً.
