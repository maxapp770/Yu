# أمان HEC+ 1.2 — نطاق المرحلة المحلية

هذه النسخة للمعاينة والعمل المحلي فقط، وليست نظام بيع أو مصادقة إنتاجياً. لا تعني إجراءات التقوية أو نجاح الفحوص أن التطبيق خالٍ من الثغرات؛ لم يُنفذ تدقيق أمان مستقل.

## الضوابط المنفذة

| المجال | التنفيذ | الحد العملي |
|---|---|---|
| الاتصال | لا تصريح INTERNET؛ blockNetworkLoads؛ موارد مضمّنة تحت أصل HTTPS محلي | لا ERPNext أو إرسال بيانات حالياً |
| الموارد | قائمة صريحة للملفات المحلية وGET فقط، رفض الأصل الآخر وuserinfo والاستعلام والمسار المرمّز | يلزم تحديث القائمة عند إضافة مورد جديد |
| WebView | منع file/content والوصول بين الأصول وmixed content والنوافذ؛ رفض الموقع وأذونات الويب؛ بلا جسر JavaScript | JavaScript مطلوب للواجهات المملوكة داخل الحزمة |
| المحتوى | CSP تمنع الاتصالات والإطارات والنماذج الخارجية والسكريبت المضمّن؛ nosniff؛ ترميز النصوص المتغيرة | السياسة لا تعوض فحص مصدر الموارد المستقبلية |
| الأسرار | لا مفاتيح API أو جلسات أو كلمات مرور مخزنة؛ مسح حقول كلمة المرور عند الإرسال والخلفية، وتعطيل التعبئة الآلية | إدخال كلمة مرور هنا لا يصادق المستخدم |
| بيانات الجهاز | تحقق صريح من الحقول والمنتجات والخيارات والحدود، إعادة حساب المجاميع، مسح مستقل لكل دور | localStorage داخل مساحة التطبيق، دون تشفير إضافي على مستوى التطبيق؛ غير مناسب لأسرار الإنتاج |
| استمرارية الحفظ | لا يعتمد تعديل أو حذف أو تسليم عند فشل الكتابة؛ استعادة آخر حالة محفوظة وتنبيه | انقطاع التطبيق أثناء الكتابة يحتاج اختبار تحمل على أجهزة فعلية |
| النسخ والخلفية | allowBackup=false وfullBackupContent=false وقواعد استبعاد Cloud/Device Transfer؛ FLAG_SECURE بالخلفية | يلزم اختبار سلوك الشركات المصنعة وقائمة التطبيقات الحديثة على هاتف فعلي |
| المندوب | دخول معاينة صريح، خروج يحجب مسارات المعاينة؛ حواجز انتقال وتأكيد تحصيل | هذه حدود رحلة تجريبية؛ الصلاحيات الحقيقية يجب فرضها على الخادم |
| التشغيل | منع WebView debugging؛ APK غير debuggable؛ شاشة إعادة محاولة لفشل المحتوى/عملية العرض | الاسترداد من قتل عملية العرض لم يُختبر بحقن عطل فعلي |

## قبل بيانات حقيقية أو نشر إنتاجي

- مصادقة خادمية وصلاحيات دقيقة لكل عميل ومندوب؛ رموز قصيرة العمر وتجديد وإبطال للجلسات. تُحفظ الأسرار بحماية Android Keystore، ولا يُضمّن سر ERPNext الإداري في APK.
- الخادم مصدر الحقيقة للأسعار والمخزون وحالات الطلب والدفع؛ تحقق وإعادة حساب على الخادم ومنع تكرار إنشاء الطلب والتسليم والتحصيل.
- إعداد قائمة خدمات HTTPS المعتمدة، وتدفق انتهاء الجلسة وفقد الشبكة وإعادة المحاولة، وسياسة خصوصية واحتفاظ وحذف معتمدة.
- توقيع إنتاجي خاص وإدارة نسخ وتحديثات، وفحص اعتماديات وثغرات واختبار اختراق مستقل واختبارات فعلية للإصدارات المدعومة.
- مراجعة التسجيلات والتحليلات والإشعارات والروابط قبل تفعيلها لتجنب كشف بيانات العملاء.

ملف التوقيع المنفصل في هذا التسليم مفتاح **اختبار** فقط بكلمة المرور القياسية android. وجود نسخة لدى مطوري المعاينة مقصود لاستمرار التحديث؛ ليس ضماناً لهوية إنتاجية ولا يجوز نشر إصدار المتجر به.

## تحديث 1.3: الإدارة

أزيل الوصول التجريبي للإدارة. الـAPK لا يمنح دوراً إدارياً محلياً، وطبقة ERPNext معطلة حتى مرحلة الربط. يُطلب System Manager من جلسة الخادم؛ يمسح سياق الإدارة عند انتهاء المهلة أو الخلفية أو رفض الخادم. كل endpoint مستقبلي يحتاج تحققاً خادمياً مستقلاً من الدور وصلاحيات المستند وسير العمل. راجع MANAGEMENT_AR.md. هذه ضوابط منفذة للمرحلة المحلية وعقد التكامل، وليست شهادة أمان إنتاجي.
