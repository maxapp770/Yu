# دليل مراجعة HEC+ 1.8

ثبّت ملف APK كتحديث على Android 10 أو أحدث؛ معرف التطبيق والتوقيع يطابقان النسخ السابقة. لا تحذف بيانات التطبيق عند التحديث.

الإدارة: **حسابي ← لوحة تحكم المتجر ← admin / 123456**. الحساب للمراجعة المحلية. تغييرات الجهاز لا تُنشر لأجهزة أخرى حتى الربط.

## الرئيسية والتسويق

1. الإدارة ← الرئيسية ← تخطيط الرئيسية والنصوص والحركة: افتح أحد الأجزاء التسعة وعدّل العنوان والنص المساعد وترتيبه وظهوره وجدولته.
2. لتغيير «تسوق بأقل الأسعار | عروض وصفقات»، افتح جزء «شريط الصفقات» وعدّل النص الظاهر للعميل.
3. لإعداد «أي قطعة 500 ر.ي»: افتح إعلاناً في شريط الصفقات، اختر أو ارفع صورته، ثم فلتر سعر البيع يساوي 500. اضبط شروط المجموعة والعلامة التجارية والتضمين والاستبعاد والفرز والحد الأقصى. عاين النتائج واحفظ، ثم اضغط الصورة من الرئيسية.
4. أضف عدة صور لأي بانر أو معرض جزء. افتح الصورة لتحديد وجهتها: صفحة، صنف، مجموعة، عرض مجمّع، فلتر مستقل أو توريث وجهة البانر.
5. اضبط اتجاه الحركة، انزلاق/تلاشي/تقليب/تكبير/بدون تأثير، مدة العرض والحركة، التكرار والأسهم والنقاط والتشغيل والإيقاف. يمكن تخصيص مدة وتأثير كل صورة.
6. الساعة الذهبية تتنقل بين العروض والصور مع الحفاظ على الصنف الأب ومكوناته وإجماليه. إدارة عروضها من «العروض ← الساعة الذهبية».

دليل مفصل وحدود الصور في MARKETING_AR.md. النصوص أسفل بطاقات المجموعات قابلة للتعديل لكل قسم ولكل بطاقة. المظهر والإطارات والألوان والسلة المتحركة من الإعدادات العامة ← مظهر التطبيق.

## بانرات مجموعات التسوق

1. الإدارة ← تسوق ← بانرات مجموعات التسوق.
2. افتح السجل الحالي أو أضف سجلاً واختر المجموعة، ثم الصورة الرئيسية والصور الإضافية.
3. اضبط وجهات الصور والفلاتر والترتيب والحركة والتوقيت وجدولة الظهور واحفظ.
4. افتح المجموعة داخل تسوق لمراجعة الحركة والنقر على صورها. إعدادات كل مجموعة مستقلة.

## طلب العميل والموصل

1. أضف صنفاً للسلة واحفظ مسودة طلب من متابعة الطلب، باسم وهاتف وعنوان صالحين.
2. من تفاصيل الطلب اضغط «بدء تجربة دورة الطلب»؛ يظهر الحدث في مركز الإشعارات.
3. الإدارة ← طلباتي ← دورة التوصيل: تأكيد الطلب، بدء التجهيز، جاهز للتوصيل، إسناد للموصل المحلي.
4. أثناء الإسناد يمكنك تحديد «مدفوع مسبقاً في التجربة»؛ وإلا يكون نقداً عند الاستلام.
5. افتح تطبيق الموصل من زر اللوحة أو معاينة المندوب في حسابي، ثم «دخول المعاينة المحلية». فعّل التوفر واقبل الطلب.
6. راجع تفاصيل العميل والعنوان والأصناف ومكونات العروض، ثم ابدأ التوصيل. عند التسليم أدخل اسم المستلم وأكد التحصيل النقدي. المدفوع مسبقاً لا يولد تحصيلاً جديداً.
7. عند التعذر أدخل السبب. ترجع الإدارة لإعادة المحاولة ثم الإسناد. يمكن رفض الإسناد مع السبب قبل قبوله.
8. العميل يرى نفس الحالة المحلية وسجل أحداثها. يمكن للإدارة تسجيل تسوية النقد مرة واحدة.
9. بعد التسليم يستطيع العميل طلب إرجاع؛ الإدارة تعتمد المرتجع وتسجل استلامه ثم رد المبلغ التجريبي مع ملاحظة.

الإلغاء متاح في المراحل المسموحة. كل أمر يتحقق من المرحلة والدور ونسخة الطلب، وفشل الحفظ لا يترك حالة جزئية. المعاينة لموصل محلي واحد وتسليم الطلب كاملاً. عمولة الطلب الجديد صفر لأن قاعدة العمولة لم تربط؛ عينات الموصل السابقة منفصلة. لا تُنفذ تسوية أو حركة أموال فعلية.

## الإشعارات والتسويق خلالها

1. الإدارة ← حسابي ← الإشعارات: استعرض الحملات الموجودة أو أضف حملة بعنوان ونص وصورة.
2. اختر الفئة والجمهور: العميل أو الموصل أو كلاهما، والوجهة المطلوبة.
3. الوجهة المباشرة «صنف» أو «مجموعة» تتطلب عنصراً واحداً. «صفحة الحملة» تجمع عدة أصناف ومجموعات مع عبارة وصورة؛ «نتائج فلتر» تفتح الأصناف المطابقة.
4. ابحث بالاسم والكود والباركود لاختيار الأصناف؛ يتوفر زر الكاميرا. البحث الحالي محلي حتى إعداد خدمة ERPNext.
5. اضبط الأولوية والنشر والانتهاء والتفعيل واحفظ. الحملة المستقبلية لا تظهر مبكراً والمنتهية تختفي.
6. جرس العميل والموصل يعرض غير المقروء؛ الضغط يفتح الوجهة ويحفظ القراءة. تتوفر الفئات وتحديد الكل وحذف إشعار.
7. تفضيلات الإشعارات تتيح إخفاء الفئات على الجهاز؛ تعطيل التسويق لا يعطل فئة الطلبات. حذف الإشعار لا يحذف الطلب.
8. الإدارة ← حسابي ← إعدادات الإشعارات: تشغيل الفئات، الحد الأقصى للحملات التسويقية الظاهرة، ومدة بقاء الأحداث المؤرخة. حد الحملات حد عرض، وليس معدل إرسال يومي.

تظهر أيضاً مسودات الرسائل والمحفظة والمرتجعات المحلية. المركز يعمل داخل التطبيق؛ إشعارات Android خارج التطبيق تحتاج خدمة Push بعد الربط. حالة القراءة لا تضيع والتنقل لا يحدث إذا فشل حفظها.

## الملفات والبناء

المصدر يحتوي مشروع Android وموارده وكتالوجه وصوره وواجهاته واختباراته وأدلة الربط والتشغيل والتراخيص. يتطلب البناء Java 17 وAndroid SDK 35 وBuild Tools 35.0.0. استخدم مفتاح المعاينة السابق المحفوظ منفصلاً؛ مفاتيح التوقيع لا توضع داخل المصدر.

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export HEC_DEBUG_KEYSTORE=/private/path/hec-preview-debug.keystore
bash build-apk.sh
```

نتيجة البناء build/HEC-phase1-debug.apk. يوضح TEST_RESULTS_AR.md نطاق التحقق وحدوده.
