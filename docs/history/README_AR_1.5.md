# الهيثم HEC+ 1.5 — مراجعة الواجهات والعروض والباركود

تحديث للمرحلة المحلية، بمعرف التطبيق والتوقيع السابقين. ثبّت APK كتحديث مع الاحتفاظ ببياناتك على Android 10 أو أحدث.

## الوصول والإعدادات

- حسابي ← لوحة تحكم المتجر: **admin / 123456**، حساب مراجعة محلي حسب طلبك.
- اللوحة تجمع **40 تبويباً في 6 أقسام**. يُحمّل المحتوى الحالي بمجرد فتح التبويب، ويتيح عرضه وتعديله وحفظه.
- النظام ← مظهر التطبيق: أسود/ذهبي/عنابي، زمردي/ذهبي، كحلي/فضي، فحمي/نحاسي، عنابي هادئ. يمكن تشغيل الإطارات الملونة واللمعان أو إيقافهما.
- تتغير ملامح الواجهة على هذا الجهاز وتُحفظ بعد إعادة التشغيل. النشر الموحد لكل المستخدمين يحتاج ربط إعدادات المتجر بالخادم.

## العروض كصنف أب

تستخدم الساعة الذهبية والحملات والعروض المجمعة محرر الصنف نفسه. افتح عرضاً موجوداً، أو أضف عرضاً واختر صنفاً أباً غير مخزني. يمكن في المراجعة إنشاء كود أب جديد وكتابة اسمه.

فعّل **إنزال اسم وكمية وسعر الصنف كما هي**، ثم راجع الاسم والكمية وسعر وحدة العرض. عند تفعيل الخيار يأتي إجمالي وحدة العرض من سعر الأب، مع توزيع مرن على المكونات بالمبلغ أو النسبة أو المتبقي التلقائي. وعند تعطيله يمكن ضبط إجمالي العرض يدوياً. كميات المكونات قد تكون كسرية، أما كمية الإضافة للصنف الأب فمن 1 إلى 999 في هذه المرحلة.

السلة تعرض الصنف الأب باسمه وكميته وسعره وتفتح تفاصيل المكونات تحته. تحفظ مسودة الطلب صفه في **Items**، ومكوناته مضروبة بكمية الأب في **Packed Items**. يُحسب الإجمالي من الأب مرة واحدة. يدعم نموذج البيانات المحلي Sales Order وSales Invoice؛ لا تُنشأ فاتورة أو طلب فعلي في ERPNext الآن.

## الأصناف والباركود

حقول اختيار الأصناف تحتوي بحثاً بالاسم والكود والباركود؛ تبقى الاختيارات محفوظة عند تغيير البحث. يشمل ذلك الصنف الأب، مكونات العرض، والمجموعات والجديد والمقترحات. أضيف مسار نتائج ERPNext عبر ناقل مخصص، لكنه **غير متصل** لعدم إعداد عنوان النظام وجلسة المصادقة وقائمة الأسعار. نتائج النسخة الحالية هي الكتالوج المحلي وتُسمى بذلك بوضوح.

من المنتجات والمخزون يمكن إدخال باركودات الصنف، رمز في كل سطر. زر الباركود في بحث الرئيسية يفتح نافذة فيها «فتح الكاميرا» وإدخال يدوي. أزرار الكاميرا موجودة أيضاً في حقول اختيار أصناف الإدارة.

في APK يعمل قارئ Camera2 وZXing داخل التطبيق؛ يطلب إذن الكاميرا عند استخدامه فقط، ويدعم EAN/UPC وCode 128/39/93 وITF وQR وData Matrix. لا تُحفظ اللقطات ولا تُرفع إلى خادم. عند رفض الإذن أو عدم وجود كاميرا يبقى الإدخال اليدوي متاحاً. ينبغي أن يكون الباركود مسجلاً للصنف لكي تظهر نتيجة؛ لا نختلق ربطاً بين باركود خارجي وصنف محلي.

## تحسين العرض

أزيل تضارب قواعد حجم صورة البطاقة الذي كان يسبب طولاً زائداً. البطاقات بصور متناسقة، اسم من سطرين، سعر واضح وأزرار كمية وإضافة مضغوطة. في تسوق تمتد منطقتا التمرير إلى خلف الشريط الشفاف، مع مسافة نهاية تسمح بإظهار آخر العناصر فوق الأزرار. الفراغات بين الأزرار تسمح بالنقر على المحتوى خلفها.

## الاختبارات والحدود

نجحت 10 رحلات متصفح للتحديث، و82 فحصاً لواجهات العميل، و13 للمشاركة والتوزيع، و18 لعقد صلاحيات الإدارة، و8 للحزمة وقيودها، و8 لمحلل الباركود الأصلي. اختبارات المصدر الخارجي تستخدم عينات مستقلة؛ ليست اتصالاً بنظامك.

تم بناء APK وتوقيعه والتحقق من موارده. **لم تُختبر كاميرا هاتف فعلي أو دورة تشغيل Android كاملة لهذا الإصدار**. نجاح فك صور الباركود لا يثبت سلوك إذن الكاميرا والتركيز على كل هاتف. نتيجة المحاكي المتعثرة الموثقة سابقاً تخص 1.4 وليست نجاحاً لـ1.5.

ما يزال ERPNext والمخزون والأسعار المعتمدة والطلبات والمدفوعات والإشعارات الفعلية ورفع الوسائط الجديدة للمرحلة التالية. لا تُستخدم بيانات دخول المراجعة في الإنتاج، ولا يقبل حارس ERPNext صلاحيات محلية.

## البناء والمصدر

الإصدار 1.5.0-phase1، رمز 6، الحزمة com.alhaitham.hec.preview. يلزم Java 17 وAndroid SDK 35 وBuild Tools 35.0.0، ومفتاح الاختبار السابق خارج المصدر:

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export HEC_DEBUG_KEYSTORE=/private/path/hec-preview-debug.keystore
./build-apk.sh
```

المكتبة المثبتة في app/libs هي ZXing core 3.5.3، مع نسخة Apache 2.0 في المصدر والحزمة. لا يحتاج القارئ Google Play Services. مفتاح التوقيع غير مرفق بالمصدر. `build/HEC-phase1-debug.apk` هو الناتج.

```bash
node tests/experience.cjs
node tests/commerce.cjs
node tests/management.cjs
node tests/security.cjs
HEC_CHROME_BIN=/path/to/chrome node tests/review15-browser.cjs
```

فحص المتصفح يحتاج Playwright. تفاصيل نموذج الربط في integration/erpnext/ITEM_CATALOG_CONTRACT_AR.md، والتغييرات وحدودها في docs/CHECKLIST_AR.md.
