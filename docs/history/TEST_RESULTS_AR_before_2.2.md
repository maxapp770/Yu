# نتائج التحقق من إصدار 2.1

- نجح 29 اختبار تراجع لخدمة الربط و19 اختباراً إضافياً للنشر والصيانة والحسابات والصلاحيات وملفات Android المسموحة.
- نجحت 21 رحلة متصفح بعقد API محلي، على عروض 320 و390 و460 بكسل، دون أخطاء تشغيل. يشمل ذلك المسودة والنشر عبر تطبيقين، إنشاء حساب عميل، إعادة محاولة الطلب بنفس المعرف، تفاصيل الطلب والإشعارات وتغيير كلمة المرور ومنع الكتابة عند اختلاف هوية المتجر.
- بُني التطبيقان باستخدام SDK 35. تحققت أسماء الحزم وversionCode 12 وversionName 2.1.0 والتوقيع ومطابقة كل أصل داخل APK للمصدر المجهز. 106 ملفات أصول للعميل و153 للإدارة. ملفات الإدارة و34 صورة للدليل مستبعدة من APK العميل.
- فُحص الدليل المستقل: 45 موضوعاً و34 صورة، دون تجاوز أفقي لشاشة الهاتف.
- نجحت مصادقة REST الحية وقراءة شركتين وقائمتي أسعار وستة مخازن. فشل bootstrap المخصص بـ HTTP 417 لعدم تثبيت hec_bridge. لم تحدث كتابة خارجية.

الأدلة في docs/evidence/2.1 وبيانات البناء في BUILD_MANIFEST.txt. لم يُشغّل هذا الإصدار على هاتف أو محاكي Android، ولم تُختبر رحلة الطلب على قاعدة بيانات ERPNext الحقيقية. الصور من التطبيق المحلي والجداول التعليمية؛ تقرير REST وحده يحتوي نتائج القراءة الفعلية.
