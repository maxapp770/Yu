# اختبارات الإصدار 2.2

مسار الخدمة الحالي هو service/hec_service. شغّل python service/tests/test_service.py بعد تثبيت service/requirements.txt: 20 اختباراً للهوية والصلاحيات والتقارير والتسعير والنشر والنقل والطلبات.

اختبارات واجهات الأعمال الحالية: commerce.cjs وengagement.cjs وexperience.cjs وfulfillment.cjs وmarketing.cjs وnotifications.cjs وsecurity.cjs وautomation.cjs وflows.cjs وmanagement.cjs. نجحت الحزم العشر. اختبارات التوصيل والأتمتة والولاء المحلية لا تثبت اتصال هذه الدورات بخادم ERP.

الملفات المسماة bridge20 وrelease21 وsplit20 وما قبلها تختبر العقد السابق داخل Frappe أو إصدارات واجهات سابقة، وليست بوابة قبول للمسار المستقل الجديد. احتُفظ بها كسجل للتطوير.

نتائج الاختبار الحالية في docs/validation-2.2. اختبار مساحة Sites استخدم SQLite وWebCrypto وتنفيذ العمليات الحقيقي مع Frappe محاكى، والمتصفح استخدم ملفات الواجهات نفسها. مصدر Git الخاص بمساحة Sites يديره مشروع الموقع المنشور بشكل مستقل.

لم يُشغّل Android على جهاز أو محاكي هنا. يلزم اختبار الكاميرا والمشاركة والأذونات وحفظ الملفات على هاتف، ورحلة حية بحساب المدير على نسخة ERPNext الفعلية قبل اعتماد الإنتاج.
